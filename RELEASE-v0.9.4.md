# Installer Analyzer v0.9.4

## Changes
- Reworked scrollbars to use a full-length track across the complete height or width of each scrollable section.
- Added a conventional browser-style draggable thumb whose size reflects the visible viewport.
- Increased the scrollbar hit area to 14 px and the minimum thumb length to 42 px.
- Added clearer hover and active-drag states.
- Preserves the v0.9.3 updater file-lock fix.

## Update test
Publish `Release/InstallerAnalyzer-Setup.exe` as GitHub release tag `v0.9.4`, then use the installed v0.9.3 application's About > Check for Updates flow.
