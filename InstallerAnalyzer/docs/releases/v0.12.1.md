# Installer Analyzer v0.12.1

## Test Mode reliability

- Adds a strict Sandbox teardown boundary between regression tests.
- Waits for Windows Sandbox client/session processes to remain absent before launching the next installer.
- Retries a fresh Sandbox launch up to three times when a .wsb starts but produces no mapped-output activity.
- Adds a longer cooldown between consecutive regression sessions to prevent the Windows Sandbox session-limit error.
- Refines Inno Setup UI detection so a short-lived generic `Setup` bootstrap window is not mistaken for an interactive installer. Persistent wizard UI is still rejected.
- Keeps the validated v0.11.45 lifecycle engine and deployment criteria unchanged.
