# v0.13.0-preview.5 — gINT main-MSI timing and diagnostics

A tracked main gINT MSI gets its own bounded startup/interaction window after a slow prerequisite chain, with a 30-minute overall discovery cap. The control center reports the main-MSI stage. Its setup log is retained automatically from the observed temp extraction location before Sandbox closes, with a bounded tail and source/truncation metadata.

A direct startup inspection created the gINT welcome dialog after roughly two minutes of Windows Installer package verification. No installation or license terms were accepted. The precise cause of the user's missing wizard remains unconfirmed; a complete gINT lifecycle is still required before export.

Retains preview.4's expected-product selection and failure reporting, the .NET 3.5 preflight and the unified Deployment tab. This is an unreleased preview; public latest remains v0.12.10.
