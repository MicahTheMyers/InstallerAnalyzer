# Installer Analyzer v0.11.25

- Rebased directly on v0.11.20, the last build confirmed to launch Windows Sandbox successfully.
- Adds hang protection in the Windows host application only; the generated Sandbox startup/bootstrap and in-Sandbox analysis script are unchanged from v0.11.20.
- After the discovery checkpoint appears, lifecycle validation has 10 minutes to finish.
- Adds a 35-minute absolute safety ceiling for runs that never reach discovery.
- On timeout, promotes the latest checkpoint to `install-analysis.json`, records the timeout reason/stage, preserves partial diagnostics, and force-closes Sandbox.
- This is the safety foundation for unattended Regression Test Mode.
