# v0.12.9 — lifecycle evidence and color picker

This release makes silent-install claims more reliable. A successful discovery probe no longer counts as a successful clean reinstall. Schema 2 records the initial install, initial uninstall, verified clean baseline, silent reinstall, silent uninstall and final absence separately. Test Mode, catalog admission, history and deployment confidence use shared validation rules. Incomplete checkpoints cannot be promoted by clearing an error or inventing an exit code.

## Engine and diagnostics

- Initial removal is monitored for installer UI, exit codes, timeout and heartbeat activity. MSI busy results receive bounded retries; registration removal receives bounded polling.
- MSI client completion no longer waits indefinitely for Windows Installer service descendants. Other executables do not receive that exception.
- Both MSI removal phases receive append-and-flush verbose logs. Diagnostic logging options stay out of the saved deployment recipe.
- Product identity prefers the exact registration key, then a matching name and publisher. Ambiguous instances and empty registration names cannot establish success.
- JSON checkpoints and final results use atomic replacement. Readers cannot consume a partially overwritten proof.
- Exit 3010 records a reboot requirement; complete evidence is still required. Exit 1605 is not accepted as proof that this lifecycle removed an installed product.
- QSetup tries its documented hidden-uninstall switch while preserving the product operation arguments. The engine does not invent a package-specific EULA property.
- Read-only MSI table inspection can identify authored removal-dialog actions when a quiet uninstall opens UI. This evidence does not authorize forcing internal MSI properties.

## Appearance

Both custom theme and accent buttons open the new color picker: saturation/brightness area, vertical rainbow hue bar, editable six-digit hex color, preview and RGB readout. There is no opacity slider. Dragging, keyboard adjustment, Apply and Cancel are supported. Invalid hex input disables Apply. Stop buttons retain the v0.12.7 red styling, with the Hacker theme exception.

## AI Assist

The optional assistant remains off by default and available only with Test Mode enabled. OpenAI and local Ollama connections are retained. The assistant receives a bounded diagnostic snapshot and has no installer execution, file-writing or catalog-writing tools. This release adds the new lifecycle fields and MSI removal logs to that snapshot, fixes bearer-token redaction, and displays a readable test label in the selector. Preview diagnostics before sending them. Live provider calls require a configured model and connection; mock transport verification is not a live provider test.

## Observed verification

Fresh Sandbox lifecycles passed for CCleaner and WinDirStat. CET's initial install succeeded, but removal opened its authored Clear User Data dialog and correctly failed the unattended lifecycle. Earlier all-package results remain historical; this release does not claim that the seven previously unresolved USB packages now pass. The accompanying release test report separates final-binary UI checks, generated-engine runs, regression checks and signing-policy limitations. ImmyBot integration was excluded at the user's request.
