# Installer Analyzer v0.11.6

## Deployment-family intelligence
- Recognizes Microsoft Office bootstrapper metadata during static analysis instead of leaving OfficeSetup.exe as Unknown solely because embedded NSIS/InstallShield strings are weak.
- Reports Office as a bootstrapper and withholds conventional silent switches until Windows Sandbox confirms Click-to-Run behavior.
- Preserves the original OfficeSetup.exe as the deployment source and treats C2RInt*.msi files as Click-to-Run implementation components.

## Adobe lifecycle reliability
- Reuses unattended arguments observed from Adobe's successful bootstrapper chain against the original Reader_en_install.exe deployment source.
- Does not depend on Adobe's ephemeral child executable or cached setup.exe as the reinstall source.
- Keeps MSI ProductCode removal as the Adobe uninstall validation strategy.

## Faster bootstrapper completion
- Installer settle detection now watches installer infrastructure rather than every descendant process.
- Acrobat, Edge, WebView2, AdobeCollabSync, Explorer, and bundled McAfee UI/background processes no longer keep the installer-active timer alive.
- Long-lived OfficeClickToRun /service activity does not block completion after the installed product is identified.
- Uses a 24-second quiet window after primary application discovery.

## Diagnostic checkpoint
- Writes install-analysis.checkpoint.json immediately after primary application discovery and before destructive lifecycle validation.
- Final install-analysis.json remains the host completion signal.
