# Installer Analyzer v0.10.1

## Squirrel.Windows support
- Added first-class static detection for Squirrel.Windows installers.
- Uses strong Squirrel-specific fingerprints including Squirrel.Windows, SquirrelSetup.log, Update.exe, and embedded `-full.nupkg` packages.
- Squirrel installers now receive an appropriate high confidence score when multiple signatures are present.
- Suggests `--silent` for Squirrel.Windows installers.
- Marks Squirrel packages as per-user deployments expected under `%LocalAppData%`.
- Makes it explicit that InstallShield `.iss` response files are not required for Squirrel.Windows.
- Prevents the InstallShield response-file recorder from being offered for Squirrel installers.

## History improvements
- History now displays installer confidence and distinguishes Static Analysis from Sandbox Validated results.
- Re-analyzing the same installer replaces its older history record, allowing corrected classifications to update cleanly.

## Safety
- The proven InstallShield Sandbox lifecycle was not rewritten in this release.
- Full automated Squirrel lifecycle validation remains disabled until its per-user uninstall/update behavior is validated against multiple real packages.
