# Installer Analyzer v0.11.30

## Bootstrapper reinstall completion fix

- Bounds silent reinstall candidates to 120 seconds.
- Treats reappearance of the expected installed application as completion instead of waiting indefinitely for normal bootstrapper/application descendants.
- Terminates only the tracked candidate tree after validation completion or candidate timeout.
- Preserves visible-installer UI rejection and candidate diagnostics.
- Immediately hydrates timeout checkpoint data into the dashboard so the discovered primary application is still shown after a host watchdog timeout.
