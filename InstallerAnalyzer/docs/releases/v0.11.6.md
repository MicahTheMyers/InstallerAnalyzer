# Installer Analyzer v0.11.6

## Silent UI validation
- Silent reinstall and silent uninstall tests now monitor visible top-level windows from the installer process tree.
- A deployment is no longer marked silently validated merely because it exits successfully and the application is detected.
- If interactive installer UI appears during a silent validation pass, validation fails and the visible window titles are recorded in install-analysis.json.
- Candidate initial silent uninstall is also rejected if it displays interactive UI.
- Existing application detection and exit-code validation remain required.
