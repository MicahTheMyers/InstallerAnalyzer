# Installer Analyzer v0.13.27

## Changes

- The Deployment tab defaults to ImmyBot and can switch to Datto RMM. Datto component kits support install, detect, and removal actions, with attachment and validation checks.
- Sandbox tracks prerequisite activity separately from the main installer, preserves handoff diagnostics, and keeps prerequisite entries separate from the target application.
- InstallShield recording and unattended replay, Test Mode, and catalog evidence handling received fixes across installer families. Validated results can be saved automatically, with deployment exports subject to their own validation checks.

## Validation

- 669 automated .NET/WPF checks passed, and all 11 Sandbox script families parsed.
- Live testing covered gINT deployment, InstallShield recording, and multiple Windows installer families. The reduced VirtualBox profile passed the Sandbox lifecycle and saved to the local catalog. WebView2 Runtime remains an open Sandbox compatibility case.

## Downloads and upgrades

Use `InstallerAnalyzer-Setup.exe` to install or upgrade, or `InstallerAnalyzer-Portable.exe` to run without installing. The executables are unsigned. Builds that enforce trusted-publisher checks require a manual upgrade.
