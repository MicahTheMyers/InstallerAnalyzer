# Installer Analyzer v0.11.37

Lifecycle-engine simplification release.

- Candidate execution is separated from candidate evaluation and cleanup.
- Failed installer candidates are recorded as validation outcomes rather than analyzer failures.
- Non-success exit codes are persisted immediately and advance after one bounded partial-install/cleanup check.
- Visible-UI rejection remains enforced.
- Candidate progression now uses explicit Execute, Evaluate, Cleanup, Detect, Next, and Validated checkpoints.
- The original deployment source remains distinct from observed/internal validation mechanisms.
- Windows Sandbox startup/session plumbing is unchanged.
