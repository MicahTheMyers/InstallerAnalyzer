# Installer Analyzer v0.11.28

## Sandbox-safe MSI lifecycle wait

- Rebased on the confirmed Sandbox-starting v0.11.26 foundation.
- Leaves the shared bootstrapper/UI process watcher unchanged.
- Silent uninstall validation now launches the uninstall command directly and waits only for that client process.
- Adds a 120-second command timeout and stage checkpoints around launch, completion, and timeout.
- Avoids waiting for persistent Windows Installer service-side msiexec processes.
- Keeps the existing host-side finalization watchdog as a fallback.
