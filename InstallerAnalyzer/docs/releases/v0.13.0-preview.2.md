# v0.13.0-preview.2 — Sandbox .NET 3.5 preflight

Adds **Settings → Windows Sandbox → Prepare .NET Framework 3.5 before Sandbox installers**. Use this for gINT and other native installers whose prerequisite is not detected automatically. Close the previous Sandbox and launch a fresh analysis after enabling the option.

The setting applies to Analyze and Test Mode. It defaults off and uses the existing command-line provisioner, matched Microsoft source and real CLR 2.0/LINQ runtime verification before the installer starts. Provisioning failure or restart-required stops the launch. All changes occur in the disposable Sandbox.

The unified Deployment tab from preview.1 remains, with ImmyBot as its default target and Datto RMM available in the dropdown. Datto tenant acceptance remains pending the user's office test. Public latest remains v0.12.10; this is a manually installed development preview.

608 .NET/WPF checks and 45 focused PowerShell provisioning checks passed. The workspace report `outputs/GINT-NETFX3-PREFLIGHT.md` records the live gINT startup result and limits. Full gINT lifecycle and licensing are not claimed by the startup check.
