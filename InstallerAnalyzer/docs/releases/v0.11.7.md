# Installer Analyzer v0.11.7

## Automatic Silent Strategy Discovery

- Ranks likely deployment strategies before lifecycle validation and tries the highest-confidence method first.
- Visible installer UI immediately rejects a candidate, terminates its process tree, and advances to the next credible strategy.
- Stops exploration if a rejected attempt changes system state that cannot be safely restored.
- Records ranked candidates, every validation attempt, rejection reason, visible windows, and the selected strategy in install-analysis.json.
- Known installer families remain deterministic and normally validate on the first attempt; candidate exploration is primarily a fallback for bootstrapper/unknown packages.
- Automatic Sandbox close now force-closes the Sandbox process after output capture so Windows Sandbox does not display its close-confirmation prompt.
- The existing Settings toggle controls automatic close and remains enabled by default; disabling it leaves Sandbox open for manual inspection.
