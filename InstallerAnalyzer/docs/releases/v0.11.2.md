# Installer Analyzer v0.11.2

## Lifecycle and bootstrapper discovery

- Fixed a race where `install-analysis.json` was written midway through lifecycle validation. The desktop app could consume that partial file and show 45% even while MSI validation was continuing.
- MSI lifecycle now remains a single atomic analysis: discovery -> ProductCode uninstall -> silent reinstall -> detection -> final silent uninstall -> absence verification.
- Weak embedded installer signatures below 50% are now informational only. They no longer select an installer family or silently assign switches such as NSIS `/S`.
- Unknown/bootstrapper EXEs now capture newly observed process command lines and recently created EXE/MSI/MSIX/AppX/MSP files from common staging locations while discovery runs.
- Unknown installers receive a longer discovery window for child/downloader activity.
- Fully Sandbox-validated install/uninstall behavior can satisfy the deployment-strategy confidence component even when static signature identification is weak.
- Preserves validated MSIX/AppX, InstallShield, NSIS, Squirrel.Windows, QSetup, Inno Setup, and MSI behavior.
