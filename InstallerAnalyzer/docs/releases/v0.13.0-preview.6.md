# v0.13.0-preview.6 — CONNECTION Client handoff diagnostics

Reports when Bentley CONNECTION Client setup has not returned control to the outer installer and gINT's main MSI has not started. Preserves current prerequisite installation logs from the guest Temp root before teardown, with bounded read-only snapshots, collection status and active installer evidence.

Also captures enforced Code Integrity events for exact executable images observed in the bootstrapper descendant tree. A local isolated control encountered a policy block of CONNECTION Client’s mbahost.dll; the user’s cause remains unconfirmed. No security policy is changed.

The supplied run confirms .NET 3.5/runtime success but contains no gINT MSI launch. The user's CONNECTION Client completion report and the still-active setup wrappers require its own installation log to diagnose the handoff. This increment does not change installer commands/timeouts or claim a successful gINT deployment.

Includes the existing main-MSI wait window, expected-product guards and unified Deployment tab. This is an unreleased preview; public latest remains v0.12.10.
