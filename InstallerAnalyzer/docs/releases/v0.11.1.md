# Installer Analyzer v0.11.1

## Lifecycle and package detection fixes
- Added first-class MSI lifecycle validation using `msiexec /i` for silent reinstall and ProductCode-based `msiexec /x /qn /norestart` for uninstall.
- Added first-class Inno Setup lifecycle behavior. Inno installers no longer wait for InstallShield response files; uninstall falls back to the Inno uninstaller with silent switches when a QuietUninstallString is unavailable.
- Added first-class MSIX/AppX static package detection, including manifest identity/version/architecture extraction when available.
- Package/container identity now outranks embedded executable strings.
- Reduced generic NSIS string evidence to supporting evidence; definitive NSIS runtime signatures are required for high confidence. This prevents bootstrapper payload strings from producing misleading 85% NSIS classifications.
- Expanded the installer picker to MSIX/AppX and bundle formats.
