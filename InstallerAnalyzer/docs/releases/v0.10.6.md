# Installer Analyzer v0.10.7

## Reliability fixes

- Fixed NSIS uninstall candidate execution when the registered executable path contains spaces, including Steam under `Program Files (x86)`.
- Uninstall commands are now parsed at the `.exe` boundary and passed to `ProcessStartInfo` as separate executable and argument values.
- Sandbox Control Center now distinguishes installer-family **candidates** from vendor-provided silent uninstall commands.
- Current Stage messages wrap instead of being clipped horizontally.
- Preserves the validated Squirrel/Discord lifecycle and existing InstallShield response-file workflow.
- Version updated consistently to 0.10.7.
