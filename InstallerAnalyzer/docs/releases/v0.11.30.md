# Installer Analyzer v0.11.30

## Reinstall launch instrumentation

- Based directly on the v0.11.29 startup-safe foundation.
- Adds checkpoint stages around silent reinstall candidate preparation, desktop/process baseline capture, ProcessStartInfo creation, Process.Start invocation, and returned PID.
- Does not change the Windows Sandbox configuration or the candidate launch semantics.
- Preserves the v0.11.28 bounded MSI uninstall behavior and host finalization watchdog.
