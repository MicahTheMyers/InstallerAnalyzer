# Installer Analyzer v0.11.15

## In-process UI diagnostics

- Uses the known-good v0.11.13 Windows Sandbox launch path.
- Adds UI diagnostics only inside the existing analysis process.
- Stores observations in the final `install-analysis.json` `UiDiagnostics` field.
- No extra watcher process, Sandbox session, mapped folder, startup command, or IPC channel is introduced.
