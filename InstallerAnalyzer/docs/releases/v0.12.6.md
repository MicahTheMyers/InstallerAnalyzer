# Installer Analyzer v0.12.6

## Generalized discovery and unattended reliability

- Process-aware UI filtering ignores Installer Analyzer's own PowerShell/console infrastructure.
- Installed application detection is authoritative before UI rejection, preventing post-install application windows from being mistaken for installer interaction.
- Second-generation Strategy Discovery inspects newly extracted MSI/setup payloads after first-generation probes and tests derived unattended candidates.
- Final uninstall now explores multiple structured silent-uninstall candidates instead of relying on one command.
- Test Mode Sandbox startup recovery uses five clean-boundary attempts with escalating cooldowns.
- Silent Only Test Mode minimizes the Windows Sandbox client after startup; Full Analysis remains visible.
- Existing v0.12.5 Strategy Discovery, MSI logging, handoff cleanup, output cleanup, and unattended queue behavior remain in place.
