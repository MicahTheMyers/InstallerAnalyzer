# Installer Analyzer v0.11.8

## Workflow reliability fixes

- Removed routine Sandbox informational MessageBox prompts from generic/unknown installer discovery.
- Silent candidate UI monitoring now follows the persistent descendant process tree even when the original bootstrapper exits or hands off to a child process.
- A visible window during silent validation immediately rejects the candidate and force-terminates every tracked descendant before cleanup/next-candidate validation.
- Reduced UI polling interval to 150 ms for faster interactive-window rejection.
- Automatic and manual Sandbox shutdown now force-terminate Windows Sandbox client processes instead of sending WM_CLOSE, avoiding the Windows Sandbox close-confirmation dialog.
- The existing Automatically close Sandbox when analysis completes setting remains enabled by default and can be disabled for manual testing.
- InstallShield retains only the prompts that are actually required for interactive response-file recording.
