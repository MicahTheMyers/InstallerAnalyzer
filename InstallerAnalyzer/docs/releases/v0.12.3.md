# Installer Analyzer v0.12.4

- Adds Test Mode selector: Full Analysis or Silent Only (Unattended).
- Silent Only never launches the normal interactive installer path. It uses detected silent arguments, fails fast when no safe silent strategy exists, bounds silent installs to six minutes, and records reboot/input/prerequisite-style failures without stopping the queue.
- Exit code 3010 is treated as successful install with reboot requested; 1641 is reported as reboot required.
- Routes mouse-wheel input from Sandbox Current Stage, Discovered Application, Generated Files, and Deployment Readiness lists to the Sandbox details scroller.
- Retains v0.12.2 clean TestResults startup and Windows Sandbox handoff safeguards.
