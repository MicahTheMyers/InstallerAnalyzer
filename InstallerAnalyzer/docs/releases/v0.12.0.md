# Installer Analyzer v0.12.0

## Test Mode foundation

- Adds an optional Test Mode tab, disabled by default and enabled from Settings.
- Creates dedicated TestInstallers and TestResults folders.
- Discovers EXE, MSI, MSIX, AppX, MSIXBundle, and AppXBundle installers.
- Adds selectable regression queue with Select All / Clear All.
- Adds Start Tests, Stop Tests, Open Test Folder, Open Output Folder, and Export Test Results ZIP.
- Stores each application result in its own run folder and writes a run Summary.json.
- Test Mode now runs the full validated lifecycle in one fresh Windows Sandbox per selected installer, captures per-application diagnostics, closes the Sandbox, and continues to the next queued installer. Failed and timed-out installers do not stop the queue.

The validated v0.11.45 single-installer Sandbox lifecycle is preserved unchanged.
