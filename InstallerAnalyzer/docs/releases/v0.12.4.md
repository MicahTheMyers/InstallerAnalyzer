# Installer Analyzer v0.12.4

## Strategy Discovery Engine — Phase 1

- Silent Only no longer immediately fails unknown/custom EXE installers when static analysis has no preferred command.
- Generates ranked unattended hypotheses and validates them inside the disposable Windows Sandbox.
- Rejects candidates that show installer UI, time out, return failure, or fail to create a detectable installed application.
- Records candidate history and rejection reasons in analysis output.
- Adds MSI verbose install logging (`msi-install.log`) to improve diagnosis of Windows Installer failures such as 1603.
- Expands QSetup and WiX Burn candidate exploration without adding application-name-specific rules.
- Preserves the v0.12.3 unattended queue and v0.11.45 lifecycle/finalization behavior.
