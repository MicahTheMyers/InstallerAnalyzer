# Installer Analyzer v0.14.4

- Analyze installers from ZIP archives with a folder tree for selecting the main setup and retaining its companion files.
- Export validated ZIP deployments to ImmyBot and Datto RMM. ImmyBot detection reports the installed version.
- Replay compatible InstallShield recordings in a fresh Sandbox and monitor validation progress.
- ACT! v24 MSI deployments create an all-users desktop shortcut after successful setup when the validated executable is present.
- Sign in to the online catalog through the profile button. The build includes the default server address and public signing key.
- Submit eligible locally validated unsigned MSI recipes for maintainer review. Catalog service administration remains separate.

This release provides a Windows setup installer and a portable executable. Use the release downloads for a manual upgrade where automatic installation requires a trusted signed installer.
