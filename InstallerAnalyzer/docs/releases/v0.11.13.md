# Installer Analyzer v0.11.13

## Sandbox regression reset

- Rebased Windows Sandbox startup and communication on the known-good v0.11.9 implementation.
- Removed the v0.11.10-v0.11.12 watcher/session approach from this branch.
- Kept silent-strategy discovery, immediate Stop Sandbox, Settings scrolling, auto-close toggle, checkpoint diagnostics, and candidate fallback from the v0.11.9 base.
- Silent UI detection now combines the existing desktop `EnumWindows` snapshot with a second in-process `MainWindowHandle`/`MainWindowTitle` check for newly created processes.
- No secondary Sandbox session, watcher process, scheduled task, remoting connection, or network session is created for UI validation.
