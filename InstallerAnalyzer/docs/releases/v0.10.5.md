# Installer Analyzer v0.10.5

## Lifecycle intelligence and discovery reliability

- Silent reinstall is only marked validated when the installer returns a success code **and** the application is detected afterward.
- Adds an **Additional package arguments** field for application-specific unattended parameters such as LPile `/License=...` without contaminating the generic QSetup strategy.
- Adds NSIS uninstall candidate validation: when a strong NSIS installer has no `QuietUninstallString`, Installer Analyzer can test the registered uninstaller with `/S` in Sandbox.
- Adds Squirrel.Windows per-user discovery under `%LocalAppData%`, including `Update.exe` + `app-*` layouts.
- Adds a Squirrel uninstall candidate based on the discovered `Update.exe --uninstall` path and requires Sandbox validation before considering it safe.
- Adds bounded waiting for bootstrapper processes and longer polling for delayed registry/filesystem registration.
- Failure diagnostics are written to `install-analysis.json` whenever the discovery script reaches completion, including discovery method, uninstall candidate, and validation error.
- Lifecycle UI now distinguishes **not attempted**, **failed validation**, and **validated** states instead of treating exit code 0 as proof of installation.
- Detection Evidence viewport increased and nested scrollbar cleanup retained.
- Version updated to v0.10.5.
