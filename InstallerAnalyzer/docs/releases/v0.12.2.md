# Installer Analyzer v0.12.2

Test Mode reliability update.

- Uses the supported Windows Sandbox CLI (`wsb list` / `wsb stop`) when available to stop the actual Sandbox environment between queued tests, with process cleanup as fallback.
- Waits for a verified quiet Sandbox boundary before launching the next installer.
- Clears prior TestResults contents when a new regression run starts; TestInstallers is preserved.
- Hides full installer paths in the queue and exposes them as hover tooltips, preserving status visibility at narrower window sizes.
- Refines Inno Setup unattended validation so a generic `Setup` owner/progress window alone does not reject a candidate; installation still must be detected successfully.
