# Installer Analyzer v0.10.9 — UI Polish

- Reworked ComboBox item and click-surface templates so Windows default light hover chrome cannot leak into dark, purple, super-dark, or Hacker themes.
- Added a subdued theme-aware Select Installer button style; Hacker mode no longer renders the large installer selector as a solid neon block.
- Rebuilt left navigation rows on a fixed icon/text grid with consistent height, padding, and vertical alignment.
- Replaced the generic ImmyBot upload arrow with a compact monochrome robot mascot icon inspired by the ImmyBot logo, while retaining the sidebar icon art style and theme colors.
- Increased the minimum scrollbar thumb size for better usability in Detection Evidence and other compact scrolling regions.
- Updated visible and package version metadata to v0.10.9.
- No installer detection, Sandbox lifecycle, QSetup/Ensoft, NSIS, Squirrel, or InstallShield validation logic was changed.
