# Installer Analyzer v0.10.7

## QSetup diagnostics and lifecycle reliability

- Records base, package-specific, and combined silent-install arguments separately.
- Records the exact silent-install command used by Sandbox validation.
- Executes silent reinstall through ProcessStartInfo so the final argument string is passed explicitly.
- Captures stdout/stderr when the installer exposes them.
- Distinguishes a successful process exit from a successful application installation.
- Shows the exact silent-install command in Sandbox Control Center.
- Promotes validated installer-family uninstall candidates to validated status in the UI.
- Preserves existing InstallShield, NSIS, Squirrel, updater, theme, and scrollbar behavior.
