# Installer Analyzer v0.11.20

- Rebased on the known-good v0.11.18 Sandbox foundation.
- Adds a lightweight McAfee process watchdog that runs as a local hidden PowerShell process inside the existing Sandbox user session.
- The watchdog polls local processes every 500 ms and terminates detected McAfee process trees with taskkill /T /F.
- The watchdog does not access mapped host folders and creates no additional Sandbox, remoting, scheduled-task, or network session.
- McAfee installers are automatically exempt.
- Records blocked McAfee processes and verifies McAfee uninstall entries are absent in install-analysis.json.
- Audited visible/runtime version strings to report v0.11.20.
