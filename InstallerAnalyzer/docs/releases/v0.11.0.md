# Installer Analyzer v0.11.0 — Automatic Deployment Discovery Foundation

## New
- Added Deployment Confidence scoring to the Sandbox Control Center.
- Scores installer identification, primary application discovery, post-install detection, silent reinstall validation, silent uninstall validation, and post-uninstall verification.
- Shows a human-readable checklist explaining exactly why a deployment is or is not ready.
- 100% confidence is required for READY FOR IMMYBOT.

## Direction
This begins the v0.11 Automatic Deployment Discovery work. The next steps are automatic silent-switch discovery, MSI-first-class analysis, and stronger behavior-based analysis for unknown installer frameworks.
