# Installer Analyzer v0.11.4

## Sandbox lifecycle controls
- Added **Stop Sandbox** to the Sandbox Control Center.
- Stopping a run closes Windows Sandbox, cancels host-side monitoring, and preserves a diagnostic `install-analysis.json` when no final analysis file exists yet.
- Added **Automatically close Sandbox when analysis completes**, enabled by default and persisted in Settings.
- Automatic shutdown occurs only after the host sees and loads the final `install-analysis.json` from the mapped output folder.

## Bootstrapper deployment improvements
- Unknown/bootstrapper analysis now prefers an observed silent child executable from the successful installation process tree over a vendor cache MSI.
- Prevents Adobe Acrobat/Reader discovery from automatically promoting the installed `AcroPro.msi` cache as the deployment source.
- Captures and reuses observed silent bootstrapper arguments when the child executable still exists.
- Child MSI promotion is restricted to staging-oriented locations such as Temp, LocalAppData, and ProgramData.
- Reduced bootstrapper process noise by no longer treating normal Acrobat/Adobe application processes as installer infrastructure.

## Microsoft Office Click-to-Run
- Recognizes `OfficeClickToRun.exe` / `OfficeC2RClient.exe` activity as Microsoft Click-to-Run.
- Keeps the original Office bootstrapper as the deployment source instead of promoting `C2RInt*.msi` integration components.
- Separates deployment mechanism/source from installed-application identity in the analysis JSON.
- Reports Click-to-Run discovery as successful even when the bootstrapper returns a non-zero code if a new Office registration is present.
- Avoids destructive lifecycle validation when no safe unattended Click-to-Run uninstall/reinstall strategy has been proven.

## Reliability
- Final discovery scripts create an analysis completion marker after writing the result.
- Manual cancellation is represented as a diagnostic result rather than a normal validation failure.
- Preserves the validated MSI, MSIX/AppX, InstallShield, NSIS, Squirrel.Windows, QSetup, and Inno Setup lifecycle behavior from previous releases.
