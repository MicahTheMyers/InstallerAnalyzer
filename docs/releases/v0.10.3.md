# Installer Analyzer v0.10.5

- Enables Sandbox installation discovery for installer technologies that do not require InstallShield response files.
- Adds a generic non-InstallShield Sandbox discovery path that captures HKLM, WOW6432Node, and HKCU uninstall entries without forcing setup.iss.
- Preserves the proven InstallShield setup.iss lifecycle for InstallShield packages.
- Fixes Sandbox gating so QSetup, NSIS, Squirrel, NVIDIA SFX, MSI, Inno, WiX and other detected installers can start analysis.
- Makes the Sandbox dashboard explicitly show when a response file is not required.
- Improves evidence presentation by labeling incidental losing signatures rather than presenting them as equal evidence.
- Fixes the footer version to v0.10.5.
- Standardizes the Detection Evidence scrollbar with the app's browser-style scrollbar and minimum draggable thumb.
- Uses theme-aware scrollbar hover color.
