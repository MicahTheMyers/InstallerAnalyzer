# Installer Analyzer v0.10.0

## Highlights
- Analysis History stored locally for the 50 most recent installers.
- Detection Intelligence ranks available detection strategies and recommends the strongest candidate.
- PowerShell Inspector performs static deployment checks before ImmyBot handoff.
- ImmyBot page now shows detection and script-readiness intelligence alongside generated scripts.
- Existing Sandbox install/uninstall validation behavior is intentionally unchanged pending broader installer testing.

## Validation note
The new intelligence/history features do not claim Sandbox validation. Runtime compatibility with additional installer families should be tested when a broader installer set is available.
