# Installer Analyzer v0.10.8

## Ensoft QSetup deployment intelligence

- Adds an Ensoft-specific QSetup deployment profile when Ensoft/LPile metadata is detected.
- Adds license choices for Cloud Subscription, Single User, and Network Client.
- Automatically builds the validated Ensoft syntax: `/silent /[EULA_accept]=Yes /[License]=...`.
- Defaults LPile/Ensoft to the Cloud Subscription profile, which passed full Sandbox reinstall/uninstall validation in v0.10.7.
- Keeps the final package arguments visible and editable so environment-specific values can still be appended.
- Warns Network Client deployments that `/[ServerIP]=...` may be required.
- Updates QSetup evidence to reflect that `/Hide` lifecycle behavior has now been Sandbox validated.
- Preserves the validated InstallShield, Squirrel.Windows, NSIS, and generic QSetup lifecycle paths.
