# Installer Analyzer v0.10.1.1

## Installer detection accuracy update
- Steam/NSIS: adds exact NSIS executable-head, runtime, and NSIS error-page fingerprints. Strong matches now reach 99% confidence.
- NVIDIA App: recognizes NVIDIA's customized 7-Zip SFX bootstrapper instead of misclassifying generic compatibility strings as InstallShield.
- NVIDIA App packages are identified from the combined 7z SFX, NVIDIA Installer Splash, NvidiaAppSetupInt, and NVIDIA App path signatures.
- NVIDIA SFX packages no longer imply an InstallShield response file; suggested silent argument is `-s`.
- Preserves Squirrel.Windows support added in v0.10.1.
