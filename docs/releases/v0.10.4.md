# Installer Analyzer v0.10.5

## Generic silent lifecycle validation

- Non-InstallShield Sandbox strategies can now continue past discovery when the installed application registers a `QuietUninstallString` and the installer has known silent arguments.
- The Sandbox validates: interactive discovery -> silent uninstall -> removal verification -> silent reinstall -> detection verification -> final silent uninstall -> final removal verification.
- Vendor-provided `QuietUninstallString` is preferred instead of reconstructing an uninstall command.
- QSetup/LPile can use `/Hide` for silent reinstall and the registered `/silent` quiet uninstaller discovered from Windows.
- InstallShield retains the existing response-file lifecycle.

## UI and workflow fixes

- Non-response-file strategies no longer show `setup.iss` and `uninstall.iss` as missing generated artifacts.
- Sandbox stages show captured quiet-uninstall strategy rather than "Waiting for uninstall recording" for non-ISS installers.
- ISS-specific controls are hidden for installer strategies that do not use response files.
- Detection Evidence now uses a dedicated inset browser-style scrolling template with a larger usable viewport.
- Version updated consistently to v0.10.5.
